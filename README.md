# StudentManagementSystem
A console-based Student Management System using Java and ArrayList.
Student Management System

A menu-driven Java application for managing student records using Object-Oriented Programming and Java Collections.

Features

- Add new student records
- View all students
- Search students by ID
- Search students by name
- Edit student details
- Delete student records
- Sort students by name
- Count total students
- Validate student information

Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Java Collections Framework
- Eclipse IDE

Student Information

The application manages student details such as ID, name, age, gender, phone number, email, address, course, and marks.

How to Run

1. Clone or download this repository.
2. Open Eclipse IDE.
3. Create or import a Java project.
4. Place the Java source files in the appropriate source folder.
5. Run "Main.java" as a Java Application.
6. Follow the menu displayed in the console.

Data Storage

Student records are stored in an "ArrayList" in memory. Records are not saved permanently and will be lost when the application exits.

Learning Objectives

This project demonstrates Java classes and objects, encapsulation, collections, CRUD operations, input validation, searching, and sorting.
